# Web Serial Terminal

[License: MIT](https://opensource.org/licenses/MIT) | [Web Serial API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)

**Альтернатива PuTTY / minicom / screen в браузере**  
Работает через Web Serial API, поддерживает UART/RS-232. Не требует установки — просто откройте `.html` файл.

---

## Основные преимущества

**1. Не требует установки**  
Один HTML-файл — открыл и работаешь. Никаких драйверов, инсталляторов, прав администратора.

**2. Быстрое подключение к порту**  
Не нужно узнавать номер COM-порта в диспетчере устройств и вводить его вручную. Просто нажмите «Подключить» и выберите нужный порт из списка активных. Браузер сам показывает все доступные последовательные порты.

**3. Адаптивная вёрстка**  
Можно сжать окно браузера в узкую панель и разместить с краю экрана — интерфейс перестроится, не мешая параллельно работать в среде разработки, терминале или других инструментах.

**4. Гибкость и кастомизация**  
Это простой HTML-файл. Вы можете:
- Изменить настройки по умолчанию (скорость, биты данных, чётность) — просто отредактируйте атрибуты `selected` в `<select>`.
- Переместить, скрыть или перекрасить любую кнопку, блок статистики — измените CSS или HTML.
- Добавить свои макросы отправки, изменить поведение чекбоксов — вся логика в одном файле, легко правится в любом текстовом редакторе.

## Возможности

- Полный контроль над портом — скорость (до 921600), биты данных, чётность, стоп-биты.
- Отправка данных — текстом или HEX-кодами (например, `48656C6C6F`).
- **Отправка нескольких строк и целых абзацев одним блоком** — в отличие от PuTTY (который отправляет символы по мере ввода или требует ручного переключения режимов), здесь можно написать многострочную команду или скрипт и отправить всё сразу.
- Приём данных — в текстовом или HEX-виде (с разбивкой по 16 байт).
- Временные метки и автопрокрутка.
- Статистика — принято/отправлено байт, время соединения, текущая скорость.
- Тёмная и светлая темы (сохраняется в localStorage).
- Лимит строк (5000) с автоматической очисткой старых.
- Чекбокс «Добавить \n» для автоматического перевода строки при отправке.

---

## Преимущество перед PuTTY: отправка многострочного текста

В классическом PuTTY отправка данных происходит либо посимвольно (как только нажата клавиша), либо после нажатия Enter (в зависимости от настроек Local Echo и Line Editing). Это неудобно, когда нужно передать несколько строк кода, конфигурацию или целый абзац.

**Данный терминал умеет:**
- Писать любой объём текста в поле ввода (хоть 100 строк).
- Редактировать его как обычный текст (перемещаться по строкам, копипастить).
- Отправить всё одним нажатием «Отправить» или Ctrl+Enter.
- Добавлять или не добавлять в конце перевод строки (галочка «Добавить \n»).

Это особенно полезно при отладке протоколов, отправке JSON, SQL-запросов, скриптов для микроконтроллеров или настройке сетевых устройств через UART/RS-232.

## Как использовать

1. Скачайте `index.html` (или откройте онлайн-версию).
2. Откройте в браузере на базе Chromium (Chrome, Edge, Brave, Opera).
3. Нажмите «Подключить» и выберите последовательный порт из списка.
4. При необходимости измените параметры (скорость и др.) в левом меню. Порт перенастраивать не нужно — изменения применятся при следующем подключении.
5. Отправляйте данные в текстовом или HEX-режиме.
6. Используйте `Ctrl+Enter` для быстрой отправки.

> При первом подключении браузер запросит разрешение на доступ к порту.

## Гибкость и кастомизация (подробнее)

Поскольку весь проект — один файл HTML/CSS/JS, вы легко можете:

- **Изменить настройки по умолчанию**  
  Например, выбрать другую скорость по умолчанию: найдите `<select id="baudRate">` и добавьте `selected` к нужному `<option>`.

- **Переместить кнопку «Очистить» в другое место**  
  Просто переставьте соответствующий HTML-элемент в коде.

- **Убрать блок статистики**  
  Закомментируйте или удалите секцию `<section class="config-section">` со статистикой.

- **Сменить тему по умолчанию**  
  Измените атрибут `data-theme="dark"` на `"light"` на теге `<body>`.

- **Добавить свои быстрые команды**  
  Напишите небольшую функцию и привяжите её к новой кнопке в интерфейсе.

Всё без перекомпиляции, сборки и лишних инструментов.

---

## Статистика в реальном времени

- **Принято** — количество байт, полученных из порта.
- **Отправлено** — количество отправленных байт.
- **Время** — длительность текущего соединения.
- **Скорость** — текущая выбранная скорость (обновляется при изменении).
